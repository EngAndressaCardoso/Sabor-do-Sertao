# Site Sabor do Sertão

## Sobre
Site Institucional focado em um restaurante que traz nos pratos a cultura pernambucana. O sistema tem como objetivo apresentar através do HTML e do CSS pratos tradicionais, a história e como entrar em contato com o restaurante, além de despertar o interesse pela gastronomia pernambucana.

Para o sistema foi pensado uma interface visualmente agradavel e intuitiva, com pouca saturação de informações para que pessoas com maior necessidade de acessibilidade possam usa-lá de forma simples. As cores foram pensadas para transmitir a origem nortestina do restaurante.

## Tecnologias utilizadas
- HTML
- CSS
- GIT

## Como executar
1. O projeto possui seu deploy feito no GitHub Pages.
2. Caso tenha sido clonado, utilize o *live server* para visualização.
